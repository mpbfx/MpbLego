# Readme

这个模块我更愿意叫他为面经小卡

为什么这么说  试想一下 很多人总是害怕大厂的面试 或者说根本就在畏惧面试

那么我希望你能在这个模块里 磨练自己对于面试的耐受力



这个模块的解锁 我更希望是在你背完大部分八股之后

你可以抱着拆礼物的心情来打开一场面试 这里可能就是别人的某次面试的经历

你可以试着看看你能不能抗住这样一场压力的面试

同时 我建议你能表达出来 你可以一边看着面试的问题 想想面试官正在提问你

你甚至可以把这一次的面试的题目发给豆包 让他作为一个严肃的面试官向你提问 

你需要不断的去复盘 去提高自己的表达能力 这样才能不断变得自信！！！
