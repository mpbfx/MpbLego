# 基本原理输出

#### 1. Map 对象使用陷阱

```plain
let map = new Map();
map['yes'] = true;      
console.log(map.get('yes')); 
console.log(map['yes']);
```

**答案：**

```plain
undefined
true
```

**<font style="color:rgb(26, 32, 41);">解析：</font>**

* <code><font style="color:rgb(26, 32, 41);">map['yes'] = true</font></code><font style="color:rgb(26, 32, 41);"> </font><font style="color:rgb(26, 32, 41);">使用了对象属性赋值方式，而不是 Map 的</font><font style="color:rgb(26, 32, 41);"> </font><code><font style="color:rgb(26, 32, 41);">set()</font></code><font style="color:rgb(26, 32, 41);"> </font><font style="color:rgb(26, 32, 41);">方法，因此不会在 Map 内部存储键值对</font>
* <code><font style="color:rgb(26, 32, 41);">map.get('yes')</font></code><font style="color:rgb(26, 32, 41);"> </font><font style="color:rgb(26, 32, 41);">查找 Map 内部存储的键值对，返回</font><font style="color:rgb(26, 32, 41);"> </font><code><font style="color:rgb(26, 32, 41);">undefined</font></code>
* <code><font style="color:rgb(26, 32, 41);">map['yes']</font></code><font style="color:rgb(26, 32, 41);"> 访问的是对象属性，返回 </font><code><font style="color:rgb(26, 32, 41);">true</font></code>

#### <font style="color:rgb(26, 32, 41);">2. 变量提升与函数作用域</font>

#### 3. 函数内变量提升

```javascript
var x = 10;
function testvalue() {
  console.log(x);
  var x = 20;
}
testvalue();
```

**答案：**

```plain
undefined
```

**解析：**

* `var x` 声明被提升到函数顶部，但赋值 `x = 20` 不会提升
* `console.log(x)` 时，`x` 已声明但未赋值，因此输出 `undefined`

#### 4. 闭包应用

```javascript
function createCounter() {
  let count = 0;
  return function() {
    count++;
    return count;
  };
}
const counter = createCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

**答案：**

```plain
1
2
3
```

**解析：**

* `createCounter` 返回一个闭包函数，闭包保持了 `count` 变量的引用
* 每次调用闭包函数都会访问并修改同一个 `count` 变量

#### 5. this 指向问题

```javascript
const obj = {
  name: 'obj',
  getName: function() {
    return this.name;
  }
};
const getName = obj.getName;
console.log(getName());
```

**答案：**

```plain
undefined
```

**解析：**

* `getName` 被赋值给全局变量后，调用时 `this` 指向全局对象（浏览器中为 `window`）
* 全局对象没有 `name` 属性，因此返回 `undefined`

#### 6. 事件循环与异步执行

```javascript
console.log('start');
setTimeout(() => {
  console.log('timeout');
}, 0);
Promise.resolve().then(() => {
  console.log('promise');
});
console.log('end');
```

**答案：**

```plain
start
end
promise
timeout
```

**解析：**

* 同步代码先执行：`start` → `end`
* 微任务（Promise）优先于宏任务（setTimeout）执行
* 因此 `promise` 在 `timeout` 之前输出

#### 7. 原型链继承

```javascript
function Parent() {
  this.name = 'parent';
}
Parent.prototype.getName = function() {
  return this.name;
};
function Child() {
  this.name = 'child';
}
Child.prototype = new Parent();
const child = new Child();
console.log(child.getName());
```

**答案：**

```plain
child
```

**解析：**

* `child` 实例继承自 `Parent` 的原型
* `getName` 方法通过原型链找到，但 `this.name` 指向 `child` 实例的 `name` 属性

#### 8. 箭头函数与 this

```javascript
const obj = {
  name: 'obj',
  getName: () => {
    return this.name;
  }
};
console.log(obj.getName());
```

**答案：**

```plain
undefined
```

**解析：**

* 箭头函数不绑定 `this`，`this` 指向定义时的上下文（此处为全局对象）
* 全局对象没有 `name` 属性，因此返回 `undefined`

#### 9. 数组方法链式调用

```javascript
const arr = [1, 2, 3, 4, 5];
const result = arr
  .filter(x => x % 2 === 0)
  .map(x => x * 2)
  .reduce((acc, curr) => acc + curr, 0);
console.log(result);
```

**答案：**

```plain
12
```

**解析：**

* `filter` 筛选出偶数：\[2, 4]
* `map` 将每个元素乘以 2：\[4, 8]
* `reduce` 求和：4 + 8 = 12

#### 11. Promise.all 与 Promise.race 的区别

```javascript
const promise1 = new Promise((resolve) => setTimeout(resolve, 100, 'one'));
const promise2 = new Promise((resolve) => setTimeout(resolve, 200, 'two'));
const promise3 = new Promise((reject) => setTimeout(reject, 50, 'error'));

Promise.all([promise1, promise2, promise3])
  .then(values => console.log(values))
  .catch(error => console.log(error));

Promise.race([promise1, promise2, promise3])
  .then(value => console.log(value))
  .catch(error => console.log(error));
```

**答案：**

```plain
error
error
```

**解析：**

* `Promise.all` 等待所有 Promise 完成，如果有一个 reject，则立即 reject
* `Promise.race` 返回第一个完成的 Promise，无论成功或失败

#### 12. async/await 错误处理

```javascript
async function fetchData() {
  try {
    const response = await fetch('https://api.example.com/data') ;
    const data = await response.json();
    return data;
  } catch (error) {
    console.log('Error:', error);
    throw new Error('Failed to fetch data');
  }
}

fetchData().then(data => console.log(data)).catch(error => console.log(error));
```

**答案：**

```plain
Error: TypeError: Failed to fetch
Failed to fetch data
```

**解析：**

* `try/catch` 捕获 fetch 和 json 解析中的错误
* `throw` 重新抛出错误，可以在调用方捕获

#### 13. 深拷贝实现

```javascript
function deepClone(obj) {
  if (obj === null || typeof obj !== 'object') return obj;
  const clone = Array.isArray(obj) ? [] : {};
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      clone[key] = deepClone(obj[key]);
    }
  }
  return clone;
}

const original = { a: 1, b: { c: 2 } };
const cloned = deepClone(original);
console.log(cloned);
```

**答案：**

```plain
{ a: 1, b: { c: 2 } }
```

**解析：**

* 递归复制对象和数组
* 处理基本类型和引用类型
* 注意循环引用问题（此实现不处理循环引用）

#### 15. 模块化导入导出

#### 16. 类与继承

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(`${this.name} makes a sound`);
  }
}

class Dog extends Animal {
  speak() {
    console.log(`${this.name} barks`);
  }
}

const dog = new Dog('Rex');
dog.speak();
```

**答案：**

```plain
Rex barks
```

**解析：**

* `extends` 实现继承
* 子类可以重写父类方法
* `super` 可用于调用父类方法

#### 17. 事件委托

// HTML: <div id="parent"><button>Click me</button></div>

#### 20. 生成器函数

```javascript
function* numberGenerator() {
  yield 1;
  yield 2;
  yield 3;
}

const gen = numberGenerator();
console.log(gen.next().value);
console.log(gen.next().value);
console.log(gen.next().value);
console.log(gen.next().value);
```

**答案：**

```plain
1
2
3
undefined
```

**解析：**

* 生成器函数使用 `yield` 暂停执行
* `next()` 方法恢复执行并获取值
* 当没有更多 `yield` 时，`value` 为 `undefined`
