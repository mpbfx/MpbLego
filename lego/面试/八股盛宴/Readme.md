# Readme

这里包含了所有常见的八股 如果能全部掌握 你基本上就可以过所有的面试

这里建议

+ 优先背诵：HTML、CSS、JS、vue/React、计算机网络、浏览器原理
+ 理解背诵：性能优化、工程化、设计模式
+ 看看就行：H5、微信小程序

我这里建议大家一定要多看看**计算机网络**和**浏览器原理** 因为这部分往往体现着你的基础能力

如果你能答的很好 那是很加分的

我也强烈建议大家把重心多放在**性能优化**和**设计模式**上面

因为他们往往都是大厂喜欢问的东西，如果你能有自己的思想 是很好的
