# Readme

本代码飞升涵盖api，hot100，手写js，场景题等方面

NO.1 算法api：提供书写算法题常见的api 涉及到数组、对象、数学等等，可先学习

NO.2 BOM/BOM：提供了这两类常见的api 这里只需要了解即可



之所以他们是NO.1 NO.2 



是因为学了算法api能帮助更快解锁 hot100 + 手撕js

    - hot100：常见算法题题解 可学习后前往官网练习
    - 手撕js：常见手撕代码 在vscode中练习即可



学了BOM/DOM 能帮助你更快解锁场景代码和场景设计

场景代码：常见场景题（非算法类的手撕）在html文件中自行测试实现

场景设计：你可以把这个理解为更加复杂的八股 更优先推荐你背八股 这部分了解即可
