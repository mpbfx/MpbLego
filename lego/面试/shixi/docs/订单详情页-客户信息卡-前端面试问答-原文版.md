# 订单详情页「客户信息卡」前端面试问答（原文版）

## 前端面试官：你是如何实现客户信息卡的？（从前端技术角度，包含 Vue / HTML / CSS / JS 等）

我会这样从“前端技术实现”角度讲 `CustomerInfoCard`（`components/OrderDetail/Cards/CustomerInfoCard.vue`）：

- **Vue 组件分层**：用一个通用的 `CardWrapper` 做容器（标题/折叠/操作按钮/模式管理/骨架屏），客户信息卡只关注表单字段、校验、业务规则；通过 `ref` 暴露 `setMode(mode)` 给父页控制进入编辑态（新建订单时 `mounted` 自动 `setMode('edit')`）。
- **模板（HTML/组件）结构**：同一份数据在两种模式渲染：`mode === 'edit'` 用 `a-form/a-form-item/a-input/a-select/a-date-picker` 组成网格表单；`mode === 'view'` 用纯展示的 grid view（label/value）避免表单控件开销和误操作。
- **响应式数据与单向数据流**：`orderInfo` 作为 prop 输入，内部用 `formData` 做本地编辑副本（`watch: { orderInfo: { immediate: true, deep: true } }` 同步），编辑时只改 `formData`，点击保存后 `this.$emit('save', this.formData)` 交给父组件统一调 API，避免子组件直接耦合接口与路由。
- **表单校验实现（JS）**：没有依赖 AntD 的表单规则系统，而是自己维护 `validateErrors` 对象；每个字段通过 `getValidateStatus/getValidateHelp` 映射到 `a-form-item` 的 `validate-status/help`，实现“逐字段错误提示 + 可控清空错误”的校验体验。
- **输入约束与联动**：
  - 数值字段用 `checkTwoDigitNumber/isNumer` 做格式校验（两位小数等）。
  - 语言方向两端下拉联动：源语言变更时若与目标相同则清空目标，反之亦然，避免非法组合。
  - 总价自动计算：`unitPrice * wordNum`；如果填写了“重复量级+权重”，则额外按权重计入重复部分，并用 `roundDecimal` 保留两位小数（在 `@change` 上触发计算，保证输入后即时反馈）。
- **异步搜索下拉（Vue 事件 + 父子通信）**：客户名称选择用 `a-select show-search` 且 `:filter-option="false"`（不走本地过滤），在 `@search` 时 `emit('user-search', keyword)`，由父页做防抖请求并回传 `userNameOptions`，组件只负责渲染 options；`@change` 再 `emit('user-change', value, option)` 让父页拿到选中项 id 做“最近订单信息回填”。
- **结算节点（交付/提单/确认/回款）的前端状态机**：用 computed（如 `canEditSendBill/canCancelIncomeFinish` 等）把“链路顺序 + 是否已填日期 + 当前状态”编码成可编辑/可撤销规则；UI 上用 `disabled` 和条件渲染的删除图标控制操作入口，撤销前弹二次确认 modal，并 `emit('cancel-date', dateType)` 交给父页调用对应取消接口。
- **CSS/布局**：
  - 编辑态用 CSS Grid（`grid-form` + `--cols: 4`）做响应式栅格表单；展示态同样用 grid（`grid-view`）保持对齐一致。
  - 局部用 flex 处理复杂字段：语言方向左右两个 select + 箭头、日期字段 + 操作图标等。
  - 使用 `scoped scss` 控制卡片内样式，同时用 `/deep/` 覆盖 Ant Design Vue 的内部样式（表单项布局、输入高度、label 对齐、必填星号等），保证 UI 一致性。
- **可扩展性与复用**：币种/语言/单位/领域/服务等选项来自配置（`~/config/*`），避免硬编码；展示态用 `formatViewValue` 做统一空值占位；货币 label 通过 `getCurrencyLabel` 统一映射。

如果面试官追问“为什么这样设计”，我会补一句：把“接口与路由”放父页统一管理、子组件只做“可复用的表单/规则/UI”，能让同一张卡在新建/详情、不同权限角色下复用，也方便后续把“客户结算”拆成独立卡（项目里已经有 `CustomerSettlementCard.vue` 的同构实现）。

### 1）通用容器：`CardWrapper`（模式管理 + 顶部操作区 + 骨架屏）

文件：`components/OrderDetail/CardWrapper.vue`

```vue
<template>
  <div class="card-wrapper" :class="{ 'is-collapsed': collapsed }">
    <div class="card-header">
      <h3 class="card-title">{{ title }}</h3>
      <div class="header-actions">
        <template v-if="!loading">
          <!-- 编辑态按钮 -->
          <template v-if="mode !== 'view'">
            <a v-if="deletable" class="action-link" @click="handleClear">清空</a>
            <a class="action-link" @click="handleCancel">取消</a>
            <a class="action-link primary" @click="handleSave">保存</a>
          </template>
          <!-- 查看态按钮 -->
          <template v-else>
            <a v-if="editable && showEdit" class="action-link" @click="handleEdit">编辑</a>
            <a v-if="showAdd && showAddButton" class="action-link" @click="handleAdd">添加</a>
            <a class="action-link" @click="toggleCollapse">{{ collapsed ? '展开' : '收起' }}</a>
          </template>
        </template>
      </div>
    </div>

    <div class="card-content" v-show="!collapsed">
      <a-skeleton v-if="loading" :active="true" :paragraph="{ rows: skeletonRows }" />
      <template v-else>
        <slot :mode="mode"></slot>
      </template>
    </div>
  </div>
</template>

<script>
export default {
  props: {
    title: String,
    defaultCollapsed: Boolean,
    editable: Boolean,
    showAdd: Boolean,
    showEdit: Boolean,
    showAddButton: Boolean,
    deletable: Boolean,
    loading: Boolean,
    skeletonRows: Number
  },
  data() {
    return { collapsed: this.defaultCollapsed, mode: 'view' }
  },
  methods: {
    setMode(newMode) {
      this.mode = newMode
      if (newMode === 'edit' || newMode === 'add') this.collapsed = false
      this.$emit('mode-change', this.mode)
    },
    handleEdit() { this.setMode('edit') },
    handleAdd() { this.setMode('add') },
    handleClear() { this.$emit('clear') },
    handleCancel() {
      this.setMode('view')
      this.$emit('cancel')
    },
    handleSave() { this.$emit('save', this.mode) },
    toggleCollapse() { this.collapsed = !this.collapsed }
  }
}
<\/script>
```

### 3）响应式数据/单向数据流：prop + 本地副本 + watch 同步

文件：`components/OrderDetail/Cards/CustomerInfoCard.vue`

```js
export default {
  props: {
    orderInfo: { type: Object, default: () => ({}) },
    sellerNameOptions: { type: Array, default: () => [] },
    userNameOptions: { type: Array, default: () => [] },
    editable: { type: Boolean, default: true },
    showEdit: { type: Boolean, default: true },
    loading: { type: Boolean, default: false }
  },
  data() {
    return {
      formData: {},
      validateErrors: {},
      cancelModal: { visible: false, title: '', content: '', dateType: '' }
    }
  },
  watch: {
    orderInfo: {
      handler(val) { this.formData = { ...val } },
      immediate: true,
      deep: true
    }
  },
  methods: {
    setMode(mode) {
      if (this.$refs.cardWrapper) this.$refs.cardWrapper.setMode(mode)
    }
  }
}
```

### 4）表单校验：`validateErrors` 驱动 `a-form-item` 的 error 展示

文件：`components/OrderDetail/Cards/CustomerInfoCard.vue`

```js
methods: {
  getValidateStatus(field) {
    return this.validateErrors[field] ? 'error' : ''
  },
  getValidateHelp(field) {
    return this.validateErrors[field] || ''
  },
  validateForm() {
    this.validateErrors = {}
    let isValid = true
    const trim = (str) => String(str ?? '').trim()

    const requiredFields = [
      { field: 'userName', label: '客户名称' },
      { field: 'addOrderTime', label: '下单日期' },
      { field: 'sellerName', label: '销售经理' },
      { field: 'projectName', label: '项目名称' },
      { field: 'orderName', label: '订单名称' },
      { field: 'srcLang', label: '源语言' },
      { field: 'desLang', label: '目标语言' },
      { field: 'unitPrice', label: '单价' },
      { field: 'wordNum', label: '量级' },
      { field: 'totalPrice', label: '总价' },
      { field: 'currencyType', label: '币种' }
    ]

    requiredFields.forEach(({ field, label }) => {
      const value = this.formData[field]
      if (value === undefined || value === null || (typeof value === 'string' && trim(value) === '')) {
        this.$set(this.validateErrors, field, `请输入${label}!`)
        isValid = false
      }
    })

    // 数字格式校验（示意）
    // if (!checkTwoDigitNumber(this.formData.wordNum)) { ... }
    // if (!checkTwoDigitNumber(this.formData.totalPrice)) { ... }

    return isValid
  },
  handleSave() {
    if (!this.validateForm()) {
      this.$message.warning('请检查表单填写是否正确')
      return
    }
    this.$emit('save', this.formData)
  }
}
```

import debounce from 'lodash.debounce'
import path from '~/config/path'

export default {
  methods: {
    handleUserSearch: debounce(async function(value) {
      if (!value) return
      const res = await this.$http.post(path.searchSalesUserList, { searchContent: value }, 'query')
      if (res.errorCode === 200 && res.data) this.userNameOptions = res.data
    }, 800),

    async handleUserChange(value, option) {
      const userId = option?.data?.attrs?.id
      if (userId) {
        this.salesOrderId = userId
        await this.getPmAndUserLastOrderInfo(userId, value)
      }
    }
  }
}

### 6）结算节点“前端状态机”：computed 控制可编辑/可撤销

文件：`components/OrderDetail/Cards/CustomerInfoCard.vue`

```js
computed: {
  canEditTranslateFinish() {
    return this.orderInfo.statusStr === '翻译中'
  },
  canEditSendBill() {
    return !this.orderInfo.sendBillTime && this.orderInfo.translateFinishTime
  },
  canEditIncomeFinish() {
    return !this.orderInfo.incomeFinishTime && this.orderInfo.sendBillTime
  },
  canEditRebateFinish() {
    return !this.orderInfo.rebateFinishTime && this.orderInfo.incomeFinishTime
  },
  canCancelTranslateFinish() {
    return !!this.orderInfo.translateFinishTime && this.orderInfo.statusStr === '已交付'
  },
  canCancelSendBill() {
    return !!this.orderInfo.sendBillTime && !this.orderInfo.incomeFinishTime
  },
  canCancelIncomeFinish() {
    return !!this.orderInfo.incomeFinishTime && !this.orderInfo.rebateFinishTime
  },
  canCancelRebateFinish() {
    return !!this.orderInfo.rebateFinishTime
  }
}
```

撤销二次确认（节选）：

```js
methods: {
  showCancelConfirm(dateType) {
    const cancelDateMap = {
      translateFinishTime: { title: '交付清除', content: '...' },
      sendBillTime: { title: '提单清除', content: '...' },
      incomeFinishTime: { title: '确认清除', content: '...' },
      rebateFinishTime: { title: '回款清除', content: '...' }
    }
    const config = cancelDateMap[dateType]
    if (config) this.cancelModal = { visible: true, ...config, dateType }
  },
  handleCancelModalOk() {
    this.$emit('cancel-date', this.cancelModal.dateType)
    this.cancelModal = { visible: false, title: '', content: '', dateType: '' }
  }
}
```

### 7）日期禁用规则：`disabledDate`（节选）

文件：`components/OrderDetail/Cards/CustomerInfoCard.vue`

```js
methods: {
  disabledDate(current) {
    if (!current) return false
    // 真实项目规则：每月 20 日前/后，允许选择的最小日期不同（这里保持与项目一致的实现方式）
    const currentTime = new Date()
    const currentYear = currentTime.getFullYear()
    const currentMonth = currentTime.getMonth()
    const currentDay = currentTime.getDate()
    const dayBigger20 = currentDay > 20
    let year = currentYear
    let month = currentMonth
    const day = 21
    if (!dayBigger20) {
      if (currentMonth === 0) { year = year - 1; month = 11 } else { month = month - 1 }
    }
    const disabledDate = new Date(year, month, day)
    return current.valueOf() < disabledDate.getTime()
  }
}
```
