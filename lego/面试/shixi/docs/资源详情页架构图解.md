## 2. 数据流转图

```plantuml
@startuml 数据流转图
!define PROCESS rectangle
skinparam backgroundColor #FEFEFE
skinparam sequenceMessageAlign center

actor "用户" as User
participant "Nuxt服务器" as Nuxt
participant "asyncData" as AsyncData
participant "数据转换层" as Transform
participant "created()" as Created
participant "mounted()" as Mounted
participant "loadLazyData()" as LazyLoad
participant "编辑交互" as Edit
participant "后端API" as API

== 1. 服务端渲染 (SSR) ==
User -> Nuxt: 请求页面
activate Nuxt
Nuxt -> AsyncData: 触发 asyncData 钩子
activate AsyncData
AsyncData -> API: 并行请求 7 个首屏 API
note right
  - getResourceBase
  - getResourceTest
  - getResourceContract
  - getResourceDomainTools
  - getResourceLanguageAbility
  - getResourceServicePrice
  - getResourceWorkingTime
end note
API --> AsyncData: 返回数据
AsyncData -> Transform: 数据转换
note right
  transformTestRecord()
  transformServicePrice()
end note
Transform --> AsyncData: 转换后的数据
AsyncData --> Nuxt: 返回初始 Data
deactivate AsyncData
Nuxt -> Nuxt: 渲染 HTML
Nuxt --> User: 返回 HTML (首屏可见)
deactivate Nuxt

== 2. 客户端激活 (Hydration) ==
User -> Created: Vue 客户端激活
activate Created
Created -> Created: 初始化业务逻辑工厂函数
note right
  - useBasicInfo
  - useOrderTime
  - useDomainTool
  - useLanguageLevel
  - useServicePrice
  - useResume
end note
Created -> Mounted: 生命周期继续
deactivate Created
activate Mounted
Mounted -> Mounted: 绑定事件监听
Mounted -> API: 加载资源经理列表
Mounted -> Mounted: 注册懒加载任务
Mounted --> User: 页面可交互 ✅
deactivate Mounted

== 3. 懒加载 (Lazy Loading) ==
User -> LazyLoad: 浏览器空闲 (requestIdleCallback)
activate LazyLoad
LazyLoad -> API: 并行请求 12 个次要 API
note right
  - getResourceResume
  - getResourceEducation
  - getResourceWorkExperience
  - getResourceProject
  - getResourceOrderStatistics
  - getResourceEvaluation
  - getResourceLevel
  - getResourceCommunication
  - getResourceOperationRecord
  - hasBaseResourceTest
end note
API --> LazyLoad: 返回数据
LazyLoad -> LazyLoad: 更新卡片数据
LazyLoad --> User: 页面完全加载 ✅
deactivate LazyLoad

== 4. 用户交互 (User Interaction) ==
User -> Edit: 点击编辑按钮
activate Edit
Edit -> Edit: 进入编辑模式\n(复制数据到 editing 变量)
Edit --> User: 显示编辑表单
User -> Edit: 修改数据
User -> Edit: 点击保存
Edit -> Edit: 表单校验
Edit -> API: 调用保存 API
API --> Edit: 保存成功
Edit -> API: 重新加载数据
API --> Edit: 返回最新数据
Edit -> Edit: 退出编辑模式
Edit --> User: 显示更新后的数据
deactivate Edit

@enduml
```

## 3. 组件通信图

```plantuml
@startuml 组件通信图
skinparam componentStyle rectangle
skinparam backgroundColor #FEFEFE

package "_id.vue (父组件)" as Parent {
  component "data: {\n  basicInfo,\n  testRecords,\n  servicePrices,\n  ...\n}" as ParentData
  component "methods: {\n  saveBasicInfo(),\n  saveTest(),\n  saveServicePrice()\n}" as ParentMethods
  component "业务逻辑层引用:\n  basicInfoMethods,\n  testMethods,\n  servicePriceMethods" as LogicRefs
}

package "子组件" {
  component "BasicInfoCard" as BasicCard {
    portin propsIn1
    portout eventsOut1
  }
  
  component "TestCard" as TestCard {
    portin propsIn2
    portout eventsOut2
  }
  
  component "ServicePriceCard" as PriceCard {
    portin propsIn3
    portout eventsOut3
  }
}

package "业务逻辑层 (utils/resource/)" as Logic {
  component "useBasicInfo.js" as UseBasic
  component "useTest.js" as UseTest
  component "useServicePrice.js" as UsePrice
}

note right of BasicCard
  **Props:**
  - basicInfo
  - isFieldEdit
  - resourceStatus
  
  **Events:**
  - @save
  - @cancel
  - @clear
end note

note right of TestCard
  **Props:**
  - testRecords
  - columns
  - isFieldEdit
  
  **Events:**
  - @save
  - @cancel
  - @delete
end note

note right of PriceCard
  **Props:**
  - servicePrices
  - columns
  - isFieldEdit
  
  **Events:**
  - @save
  - @cancel
  - @delete
end note

ParentData -down-> propsIn1 : Props 传递\nbasicInfo
ParentData -down-> propsIn2 : Props 传递\ntestRecords
ParentData -down-> propsIn3 : Props 传递\nservicePrices

eventsOut1 -up-> ParentMethods : @save 事件\n触发 saveBasicInfo()
eventsOut2 -up-> ParentMethods : @save 事件\n触发 saveTest()
eventsOut3 -up-> ParentMethods : @save 事件\n触发 saveServicePrice()

LogicRefs -down-> UseTest : this.testMethods.save()
LogicRefs -down-> UsePrice : this.servicePriceMethods.save()

  this.basicInfoMethods =
```

## 4. 状态机流转图

```plantuml
@startuml 资源状态机
skinparam backgroundColor #FEFEFE
skinparam state {
  BackgroundColor<<development>> #E8F5E9
  BackgroundColor<<onsite>> #E3F2FD
  BackgroundColor<<negative>> #FFEBEE
  BackgroundColor<<terminal>> #F5F5F5
  BorderColor #424242
  FontSize 12
}

title 资源状态机流转图

state "开发阶段" as DevStage {
  state "新开发\n(0)\neditable" as New <<development>>
  state "沟通中\n(20)\neditable" as Communicating <<development>>
  state "不合作\n(-10)" as NoCooperation <<negative>>
  state "备选库\n(40)\neditable" as Backup <<development>>
  state "测试中\n(50)\neditable" as Testing <<development>>
  state "测试不通过\n(-20)" as TestFailed <<negative>>
  state "测试通过\n(80)\neditable" as TestPassed <<development>>
  state "签约中\n(90)\neditable" as Signing <<development>>
  state "签约终止\n(110)" as SignTerminated <<terminal>>
  state "签约完成\n(100)\neditable" as SignCompleted <<development>>
  
  [*] --> New
  
  New --> Communicating : 手动编辑
  New --> NoCooperation : 手动编辑
  New --> Backup : 手动编辑
  
  Communicating --> NoCooperation : 手动编辑
  Communicating --> Backup : 手动编辑
  
  NoCooperation --> Communicating : 手动编辑
  NoCooperation --> Backup : 手动编辑
  
  Backup --> Communicating : 手动编辑
  Backup --> NoCooperation : 手动编辑
  
  Communicating --> Testing : 添加测试ID
  Backup --> Testing : 添加测试ID
  
  Testing --> TestFailed : 手动编辑
  Testing --> TestPassed : 手动编辑
  
  TestFailed --> TestPassed : 手动编辑
  TestPassed --> TestFailed : 手动编辑
  
  TestPassed --> Signing : 手动编辑
  
  Signing --> SignTerminated : 手动编辑
  Signing --> SignCompleted : 签约完成
  
  SignCompleted --> OnsiteStage : 手动编辑
}

state "在场阶段" as OnsiteStage {
  state "已入库\n(120)\neditable\n!deletable" as Onsite <<onsite>>
  state "已解约\n(-30)\neditable\n!deletable" as Terminated <<terminal>>
  
  Onsite --> Terminated : 手动编辑
}

note right of New
  开发阶段所有状态:
  - 可编辑 (editable)
  - 可删除 (deletable)
end note

note right of Onsite
  在场阶段所有状态:
  - 可编辑 (editable)
  - 不可删除 (!deletable)
  - 需校验必填字段
end note

note bottom of Testing
  触发条件:
  添加测试ID后
  自动流转到"测试中"
end note

@enduml
```
