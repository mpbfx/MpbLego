# 资源报表跳转功能说明

## 功能概述

在资源数据报表页面，点击任意柱状图数据选项，可直接跳转至对应的资源管理页面，并自动应用对应的筛选条件进行检索。

## 跳转规则

### 跳转到资源开发管理页面

以下图表点击后跳转到 **资源开发管理** 页面：

#### 1. 资源状态
- 点击任意状态柱（如"新开发"、"沟通中"、"已入库"等）
- 跳转后自动筛选对应状态的资源

#### 2. 开发渠道
- 点击任意渠道柱（如"Boss"、"Linkedin"、"Proz"等）
- 跳转后自动筛选对应渠道的资源

#### 3. 结算类型
- 点击任意类型柱（如"海外个人"、"国内个人"、"海外供应商"等）
- 跳转后自动筛选对应结算类型的资源

#### 4. 语种分布（母语）
- 点击任意语言柱
- 跳转后自动筛选对应母语的资源

#### 5. 服务分布
- 点击任意服务柱（如"翻译"、"MTPE"、"审校"等）
- 跳转后自动筛选对应服务的资源

#### 6. 游戏标签（类型/主题）
- 点击任意游戏标签柱
- 跳转后使用领域标签进行筛选

#### 7. 影视标签（长度/题材）
- 点击任意影视标签柱
- 跳转后使用领域标签进行筛选

### 跳转到资源在场管理页面

以下图表点击后跳转到 **资源在场管理** 页面：

#### 1. 译员级别
- 点击任意级别柱（如"S"、"A"、"B"、"C"、"黑"等）
- 跳转后自动筛选对应级别的资源

#### 2. 质量平均分
- 点击不跳转（暂不支持）

#### 3. 配合平均分
- 点击不跳转（暂不支持）

#### 4. 时效平均分
- 点击不跳转（暂不支持）

#### 5. 接单量
- 点击任意接单量区间柱（如"大于200单"、"100-200单"等）
- 跳转后自动筛选对应接单量的资源

#### 6. 最近接单时间
- 点击任意时间区间柱（如"一周内"、"一月内"等）
- 跳转后自动筛选对应时间范围的资源

## 技术实现

### 报表页面（resourceReport.vue）

1. **图表点击事件绑定**
   - 在 `renderChart` 方法中为每个图表绑定 `click` 事件
   - 点击时调用 `handleChartClick` 方法

2. **参数映射与路由选择**
   - 根据图表类型决定跳转目标页面（开发管理 or 在场管理）
   - 将图表数据项映射为对应的筛选参数
   - 保留报表页当前的筛选条件（领域、渠道、资源经理）

3. **路由跳转**
   - 使用 `this.$router.push` 跳转到对应页面
   - 通过 query 参数传递筛选条件

### 资源开发管理页面（interpreterAndSuppliers.vue）

1. **URL参数接收**
   - 在 `mounted` 钩子中检查 `$route.query`
   - 将 URL 参数转换为筛选参数格式

2. **筛选组件同步**
   - 通过 ref 访问筛选组件
   - 将参数同步到筛选组件的表单

3. **自动应用筛选**
   - 调用 `applyFiltersWithParams` 方法
   - 使用筛选接口获取数据

### 资源在场管理页面（onSite.vue）

1. **URL参数接收**
   - 在 `mounted` 钩子中检查 `$route.query`
   - 支持的参数：`translatorLevel`、`orderCount`、`orderTimeRange`、`domain`、`service`、`language`、`domainTags`、`resourceManager`、`resourceType`

2. **筛选组件同步**
   - 通过 ref 访问在场筛选组件
   - 将参数同步到筛选组件的表单

3. **自动应用筛选**
   - 调用 `applyFiltersWithParams` 方法
   - 使用在场筛选接口获取数据

## 参数映射表

### 跳转到资源开发管理

| 图表类型 | 参数名 | 说明 |
|---------|--------|------|
| 资源状态 | resourceStatus | 状态值（0, 20, -10, 40, 50, -20, 80, 90, 110, 100, 120, -30） |
| 开发渠道 | channel | 渠道名称 |
| 结算类型 | resourceType | 类型值（0, 2, 8, 10） |
| 语种分布 | language | 语言代码 |
| 服务分布 | service | 服务名称 |
| 游戏/影视标签 | domainTags | 标签名称 |

### 跳转到资源在场管理

| 图表类型 | 参数名 | 说明 |
|---------|--------|------|
| 译员级别 | translatorLevel | 级别（S, A, B, C, 黑） |
| 接单量 | orderCount | 接单量区间 |
| 最近接单时间 | orderTimeRange | 时间区间 |

## 用户体验优化

1. **视觉反馈**
   - 鼠标悬停时柱状图颜色加深
   - 鼠标指针变为手型（pointer）

2. **筛选条件保留**
   - 跳转时保留报表页的筛选条件（领域、渠道、资源经理）
   - 避免筛选条件丢失

3. **空数据处理**
   - 点击数值为 0 的柱状图不会跳转
   - 避免无意义的查询

4. **功能提示**
   - 质量平均分、配合平均分、时效平均分图表点击不跳转（暂不支持）

## 使用示例

### 示例1：查看某级别译员
1. 用户在资源报表页面查看"译员级别"图表
2. 点击"A"级柱状图
3. 自动跳转到资源在场管理页面
4. 筛选条件自动设置为"译员级别=A"
5. 列表显示所有A级译员

### 示例2：查看最近接单情况
1. 用户在资源报表页面查看"最近接单时间"图表
2. 点击"一周内"柱状图
3. 自动跳转到资源在场管理页面
4. 筛选条件自动设置为"最近接单时间=一周内"
5. 列表显示所有一周内接过单的资源

### 示例3：查看接单量分布
1. 用户在资源报表页面查看"接单量"图表
2. 点击"大于200单"柱状图
3. 自动跳转到资源在场管理页面
4. 筛选条件自动设置为"订单数量=大于200单"
5. 列表显示所有接单量大于200的资源
