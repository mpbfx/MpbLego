## 常见操作速查

### 1. 添加新的卡片模块

**步骤**:
1. 创建卡片组件 `components/ResourceDetail/Cards/NewCard.vue`
2. 在 `config/resourceDetailConfig.js` 添加 Tab 配置
3. 在 `_id.vue` 中导入组件并添加到模板
4. 创建逻辑模块 `utils/resource/useNewModule.js`
5. 在 `_id.vue` 的 `created` 中初始化逻辑
6. 添加 API 路径到 `config/path.js`

**模板**:
```vue
<!-- components/ResourceDetail/Cards/NewCard.vue -->
<template>
  <card-wrapper
    title="新模块"
    :editable="true"
    @save="handleSave"
    @cancel="handleCancel"
  >
    <template v-slot="{ mode }">
      <!-- 查看态 -->
      <div v-if="mode === 'view'">
        <!-- 展示内容 -->
      </div>
      
      <!-- 编辑态 -->
      <a-form v-else>
        <!-- 表单内容 -->
      </a-form>
    </template>
  </card-wrapper>
</template>

<script>
export default {
  name: 'NewCard',
  props: {
    data: { type: Object, required: true }
  },
  methods: {
    handleSave() {
      this.$emit('save', this.formData)
    },
    handleCancel() {
      this.$emit('cancel')
    }
  }
}
</script>
```

## 常见问题快速解决

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 数据不显示 | asyncData 未执行 | 检查路由参数，在 mounted 中补充加载 |
| 表单校验失败 | 未使用 v-decorator | 使用 Ant Design 表单规范 |
| 权限控制不生效 | 状态未更新 | 检查 developmentInfo.status |
| 状态无法切换 | 状态机配置错误 | 检查 statusMachine 配置 |
| 页面卡顿 | 数据量过大 | 使用虚拟滚动或分页 |
| 内存泄漏 | 事件监听未移除 | 在 beforeDestroy 中清理 |
