# 资源报表页面性能优化文档

## 问题背景

资源报表页面 `pages/resourceManagement/resourceReport.vue` 包含 **15 个 ECharts 图表**，页面首次加载时同时初始化和渲染所有图表，导致：

- 主线程长时间阻塞
- 页面出现明显卡顿
- 用户体验差

## 优化方案

采用 **IntersectionObserver 懒加载** + **requestAnimationFrame 分帧渲染** 策略。

---

## 核心代码讲解

### 1. 新增数据属性

```javascript
data() {
  return {
    // ... 原有属性

    // 存储图表配置，用于懒加载时获取渲染参数
    pendingChartConfigs: {},

    // IntersectionObserver 实例
    chartObserver: null,

    // 已初始化的图表 ref 集合，防止重复初始化
    initializedCharts: new Set(),
  }
}
```

| 属性 | 类型 | 作用 |
|------|------|------|
| `pendingChartConfigs` | Object | 存储每个图表的配置（数据、排序规则等），供懒加载回调使用 |
| `chartObserver` | IntersectionObserver | 观察图表容器是否进入视口 |
| `initializedCharts` | Set | 记录已初始化的图表，避免重复渲染 |

---

### 2. 初始化 IntersectionObserver

```javascript
initChartObserver() {
  this.chartObserver = new IntersectionObserver(
    (entries) => {
      entries.forEach((entry) => {
        if (entry.isIntersecting) {
          // 图表进入视口
          const chartDom = entry.target
          const refName = this.getRefNameByDom(chartDom)

          if (refName && !this.initializedCharts.has(refName)) {
            // 标记为已初始化，防止重复渲染
            this.initializedCharts.add(refName)

            const config = this.pendingChartConfigs[refName]
            if (config) {
              // 使用 requestAnimationFrame 分散渲染压力
              requestAnimationFrame(() => {
                this.renderChart(
                  config.ref,
                  config.data,
                  config.order,
                  config.showPercent,
                  config.isLanguage ? (code) => getLabelByValue(code) || code : null
                )
              })
            }

            // 已渲染，停止观察该元素
            this.chartObserver.unobserve(chartDom)
          }
        }
      })
    },
    {
      root: null,           // 使用视口作为根
      rootMargin: '220px',  // 提前 220px 开始加载（预加载）
      threshold: 0.1,       // 10% 可见即触发
    }
  )
}
```

**关键配置说明：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `root` | `null` | 使用浏览器视口作为观察区域 |
| `rootMargin` | `'220px'` | 扩展观察区域，提前加载即将进入视口的图表 |
| `threshold` | `0.1` | 元素 10% 可见时触发回调 |

**为什么用 `requestAnimationFrame`：**
- 将渲染任务推迟到浏览器下一帧
- 避免多个图表同时渲染导致帧率下降
- 让浏览器有机会处理用户交互

### 3. DOM 到 Ref 名称的映射

```javascript
getRefNameByDom(dom) {
  const refNames = [
    'statusChart', 'channelChart', 'settlementChart', 'levelChart',
    'qualityChart', 'cooperationChart', 'timelinessChart', 'orderCountChart',
    'lastOrderChart', 'languageChart', 'serviceChart', 'gameTypeChart',
    'gameThemeChart', 'filmLengthChart', 'filmGenreChart'
  ]
  for (const refName of refNames) {
    if (this.$refs[refName] === dom) {
      return refName
    }
  }
  return null
}
```

IntersectionObserver 回调只能获取 DOM 元素，需要反向查找对应的 Vue ref 名称。

---

### 4. 修改 processData - 懒加载逻辑

```javascript
processData(data) {
  // ... 更新统计数据

  this.$nextTick(() => {
    chartConfigs.forEach((config) => {
      // 存储配置供懒加载使用
      this.pendingChartConfigs[config.ref] = config

      const chartDom = this.$refs[config.ref]
      if (chartDom) {
        // 情况1: 图表已初始化（用户点击筛选后刷新数据）
        if (this.initializedCharts.has(config.ref) && this.charts[config.ref]) {
          // 直接更新数据，不重新初始化
          const chartData = this.transformStats(
            config.data,
            config.order,
            config.showPercent,
            config.isLanguage ? (code) => getLabelByValue(code) || code : null
          )
          this.charts[config.ref].setOption(
            this.getChartOption(chartData, config.showPercent, config.ref)
          )
        } else {
          // 情况2: 图表未初始化，交给 observer 观察
          this.chartObserver.observe(chartDom)
        }
      }
    })
  })
}
```

**两种情况处理：**

| 场景 | 处理方式 |
|------|----------|
| 首次加载 | 注册到 observer，等待进入视口时渲染 |
| 筛选刷新 | 直接调用 `setOption` 更新已有图表数据 |

---

### 5. 生命周期管理

```javascript
mounted() {
  this.loadManagerList()
  this.fetchData()
  this.debouncedResize = debounce(this.handleResize, 200)
  window.addEventListener('resize', this.debouncedResize)
  // 初始化 Observer
  this.initChartObserver()
},

beforeDestroy() {
  window.removeEventListener('resize', this.debouncedResize)
  // 清理 Observer，防止内存泄漏
  if (this.chartObserver) {
    this.chartObserver.disconnect()
    this.chartObserver = null
  }
  Object.values(this.charts).forEach((chart) => chart && chart.dispose())
}
```

## 优化效果对比

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 首屏渲染图表数 | 15 个 | 3-4 个（视口内） |
| 主线程阻塞时间 | 长 | 分散到多帧 |
| 滚动时渲染 | 已全部渲染 | 按需渲染 |
| 内存占用 | 立即占满 | 渐进式增长 |

```
    │
    ▼

    │
    ▼

    │
    ▼

    │
    ▼

    │
    ▼

```

---

## 注意事项

1. **rootMargin 的选择**：当前设置 `220px`，约等于一个图表卡片的高度，确保用户滚动时图表已提前加载完成

2. **Set 去重**：`initializedCharts` 使用 Set 数据结构，O(1) 时间复杂度判断是否已初始化

3. **内存清理**：`beforeDestroy` 中务必调用 `disconnect()` 断开观察，避免内存泄漏
