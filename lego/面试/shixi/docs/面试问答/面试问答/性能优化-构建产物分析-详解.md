## 3. 分包策略：为什么要把 UI / 图表 / PDF 拆出来

来源：`nuxt.config.js:193`

```js
const splitChunks = config.optimization && config.optimization.splitChunks
const cacheGroups = splitChunks && splitChunks.cacheGroups
if (cacheGroups) {
  cacheGroups.ui = {
    test: /[\\/]node_modules[\\/](ant-design-vue|element-ui)[\\/]/,
    name: 'ui',
    chunks: 'all',
    priority: 40
  }
  cacheGroups.charts = {
    test: /[\\/]node_modules[\\/]echarts[\\/]/,
    name: 'charts',
    chunks: 'all',
    priority: 30
  }
  cacheGroups.pdf = {
    test: /[\\/]node_modules[\\/](pdfjs-dist|vue-pdf-embed)[\\/]/,
    name: 'pdf',
    chunks: 'all',
    priority: 30
  }
}
```

面试讲法：

- 这些库体积大、更新频率低、跨页面复用高：拆成独立 chunk 后，浏览器可以长期缓存（尤其是 `ui`）。
- `priority` 让命中规则更稳定，避免大包被不小心合并进其他 chunk。
- `chunks: 'all'` 允许同步/异步依赖都参与分包。

## 4. moment locale 剔除：为什么能显著减包

来源：`nuxt.config.js:183`

```js
if (ctx.isClient) {
  config.plugins = config.plugins || []
  config.plugins.push(
    new webpack.IgnorePlugin({
      resourceRegExp: /^\.\/locale$/,
      contextRegExp: /moment$/
    })
  )
}
```

面试讲法：

- `moment` 默认会把大量 locale 以动态 require 的方式打包进来；如果项目不需要多语言 locale（或使用更轻量的时间库），可以通过 IgnorePlugin 把 locale 整体剔除。
- 只在 `ctx.isClient` 生效，避免影响 SSR server bundle 的行为。

## 7. 面试题库（Q&A 速记）

### Q1：你们怎么判断“拆包是否有效”？

看两个维度：  
1) `ui/charts/pdf` 这些 chunk 是否稳定生成且体积合理（脚本的 focus chunks + build log 聚合）；  
2) `initial` 总体积是否下降、Top10 最大 JS 是否被拆散（manifest 统计）。

### Q2：为什么要剔除 moment locale？风险是什么？

收益是显著减包；风险是如果业务需要某些 locale（例如 `moment.locale('fr')`），会在运行时报错或表现异常。解决方式是只保留需要的 locale 或迁移到更轻量的库。

### Q3：`--analyze` 和你们的 ps1 脚本有何区别？

- `--analyze` 更适合定位“模块组成/谁引入了谁”；  
- ps1 更适合做“可量化指标/回归对比”（initial/async、TopN、chunk 聚合），更像一个轻量的 PR 体积报告。

## 8. 改进建议（面试加分项）

1) 在 CI 里加入“构建产物体积阈值”检查（例如 initial JS 超过阈值即失败），把性能回归前置。  
2) 对 `moment` 的使用做一次全仓审计：能替换为 `dayjs` 或原生 `Intl` 的尽量替换，进一步减包。  
3) 对 `echarts/pdfjs` 做按需引入或路由级懒加载，确保不进入 initial。
