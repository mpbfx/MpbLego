## 资源管理页面性能优化重构总结

### 问题背景
资源管理页面（`interpreterAndSuppliers.vue` 和 `onSite.vue`）存在多处交互卡顿：
1. 筛选区输入时卡顿
2. 点击"自定义表头"展开下拉框时卡顿
3. 点击"沟通/评价"打开弹窗时卡顿

**根本原因**：页面组件体量过大（3000+ 行），任何响应式数据变化都会触发整个组件（包含 50 行表格）重新渲染。

### 解决方案
利用 Vue 组件边界隔离重渲染范围，将频繁触发状态变化的 UI 区域提取为独立子组件。

### 新增组件

| 组件 | 路径 | 用途 |
|------|------|------|
| ResourceFilter | `components/ResourceFilter/ResourceFilter.vue` | 资源开发管理页筛选区 |
| OnSiteFilter | `components/ResourceFilter/OnSiteFilter.vue` | 资源在场管理页筛选区 |
| CustomColumnDropdown | `components/Table/CustomColumnDropdown.vue` | 自定义表头下拉框（通用） |
| CommunicationDialog | `components/ResourceDialog/CommunicationDialog.vue` | 沟通记录弹窗 |
| EvaluationDialog | `components/ResourceDialog/EvaluationDialog.vue` | 评价记录弹窗 |

### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `interpreterAndSuppliers.vue` | 引入 ResourceFilter、CustomColumnDropdown、CommunicationDialog |
| `onSite.vue` | 引入 OnSiteFilter、CustomColumnDropdown、EvaluationDialog |
| `config/path.js` | 添加在场资源 API 路径 |

### 架构变化

```
重构前:
┌─────────────────────────────────────┐
│ Page Component (3000+ lines)        │
│ ├── 筛选区 (内联)                    │ ← 输入触发整页重渲染
│ ├── 自定义表头下拉框 (内联)           │ ← 展开触发整页重渲染
│ ├── 沟通/评价弹窗 (内联)             │ ← 打开触发整页重渲染
│ ├── 表格 (50行数据)                  │
│ └── 其他弹窗                         │
└─────────────────────────────────────┘

重构后:
┌─────────────────────────────────────┐
│ Page Component                      │
│ ├── <ResourceFilter />              │ ← 独立组件
│ ├── <CustomColumnDropdown />        │ ← 独立组件
│ ├── <CommunicationDialog />         │ ← 独立组件
│ ├── <EvaluationDialog />            │ ← 独立组件
│ ├── 表格 (50行数据)                  │
│ └── 其他弹窗                         │
└─────────────────────────────────────┘
```

### 组件通信设计

| 组件 | 通信方式 |
|------|----------|
| 筛选组件 | 事件：`@search`、`@filter`、`@reset` |
| 自定义表头 | v-model 双向绑定 + `storage-key` 自动持久化 |
| 弹窗组件 | ref 调用 `open(row)` 方法 + `@saved` 事件回调 |

### 性能提升

| 操作 | 重构前 | 重构后 |
|------|--------|--------|
| 筛选区输入 | 整页重渲染（卡顿） | 仅筛选组件重渲染（流畅） |
| 展开自定义表头 | 整页重渲染（卡顿） | 仅下拉组件重渲染（流畅） |
| 打开沟通/评价弹窗 | 整页重渲染（卡顿） | 仅弹窗组件重渲染（流畅） |

### 代码精简

从页面组件移除的冗余代码：
- 筛选相关：20+ 个 data 字段、5+ 个 methods、100+ 行样式
- 自定义表头：`customColumnVisible` 状态、`handleColumnChange` 方法、相关样式
- 弹窗相关：`communicationDialogVisible`/`evaluationDialogVisible` 状态、表单数据、CRUD 方法、80+ 行样式

### 功能一致性
- 所有筛选字段、选项值、API 参数映射保持不变
- 展开/收起状态、自定义列选择持久化到 localStorage
- 弹窗表单验证、保存逻辑、成功后刷新列表等行为完全一致
